# 모델의 개입 반응을 해석하는 방법론: 설계와 검증

작성: 2026-09-07. 사용자 교정: 연구 목표는 이미지 편집 제품이 아니라
방법론·해석론이다. 이 문서는 과거 연구의 성공 판정을 소급 변경하지 않는다.

## 1. 연구 질문과 산출물

**모델 내부 표현에 가한 개입이 어떤 반응과 상호작용을 만들며,
그 해석이 어느 조건과 변화 범위에서 성립하는가?**

분석 대상은 고정한 모델 `F`, 분석할 입력/중간 표현 `z`, 개입 경로,
출력의 관측 방법 `phi`다. 이미지 생성기는 기존 실험 자산으로 활용한다.
정의는 벡터 출력에도 적용되지만 다른 모델 계열에 대한 유효성은 별도 실험 대상이다.

산출물은 다음 정보를 함께 담는 분석 결과다.

- 부호와 크기를 보존한 개입 반응: 무엇이 얼마나 증가/감소하는가?
- 두 개입의 공동 반응에서 각각의 반응을 뺀 상호작용.
- 1차 설명과 실제 유한 개입 결과의 차이, 확인한 개입 크기별 유효 여부.
- 관측 표현, 개입 정의, 미분 가능성, 수치 오차와 미검증 범위.

실사용 대상은 연구자의 모델 비교, 표현 학습 평가, 실패 원인 분석이다.
논문상의 목표는 이 분석으로 잘못된 해석을 줄이거나 유효한 해석의 범위를
더 정확히 식별하는 것이다. 안정적으로 같은 그림을 만드는 것만으로 성공하지 않는다.

| 혼합 Hessian → 순서 효과 | 상수 잠재 방향의 이동은 순서를 바꾸어도 같은 점에 도달한다 | 공동 반응의 비가산성과 순서 비가환성을 별도 대상으로 정의한다 |

| saliency 상관·군집 | 절댓값은 방향 부호를, 상관은 크기 차이를 숨길 수 있다 | 반응 방향·크기와 독립 의미 평가를 함께 보고한다 |

특히 C4의 기존 절댓값 상관 수치는 그대로 비선형성의 증거로 재사용하지 않는다.
이는 원래 모든 관찰이 거짓이라는 판정이 아니라 해당 측정의 식별력 문제다.

## 3. 최소 수학 설계

### 3.1 개입과 관측의 명시

모델의 확률성을 고정한 뒤 `q(t) = phi(F(gamma(t)))`, `gamma(0)=z`를 정의한다.
기본 개입은 `gamma(t)=z+t b`다. 다른 좌표에서 같은 개입을 비교할 때는
변환한 경로 전체를 사용한다. 각 좌표에서 새로 그린 직선은 일반적으로 다른 개입이다.

관측 `phi`를 바꾸면 분석 대상도 바뀐다. 예를 들어 `F(t)=t`여도
`phi(x)=x²`를 관측하면 2차 반응이 생긴다. 이를 모두 모델 자체의 곡률로 해석하지 않는다.
고정한 관측 공간·단위·노름에서 비교하고 다른 관측 표현의 결과도 따로 보고한다.

`q`가 미분 가능한 기준점에서 부호를 보존한 반응 `v=q'(0)`를 계산한다.
절댓값과 색상 지도는 표시용 후처리이며 상호작용 계산의 입력으로 쓰지 않는다.

### 3.2 유한 개입에서 설명의 오차

`Delta(t) = q(t)-q(0)`

`R(t) = Delta(t)-t v`

`R`는 1차 설명의 실제 유한 개입 오차다. 작은 반응의 상대 오차 폭주를 막기 위해
절대 오차와 반응 크기를 함께 보고하고 다음처럼 사전에 정한 기준으로 판정한다.

`||R(t)|| <= atol + rtol * max(||Delta(t)||, ||t v||)`

`atol`은 반복 계산의 수치 오차와 출력 단위를 고려해 교정 세트에서 정하고,
`rtol`은 용도별 허용 오차로 사전에 정한다. 무반응 사례는 별도로 표시한다.
상수 설명이 안정성만으로 통과하지 않도록 실제 변화에 대한 충실도를 필수 평가한다.

`q`가 경로 구간에서 C²이면 다음 고전적 항등식이 성립한다.

`R(t) = integral_0^t (t-s) q''(s) ds`

따라서 **구간 전체**에서 검증한 `||q''|| <= M`이 있을 때만
`||R(t)|| <= M t²/2`라는 연속 구간 보장을 말한다.
기준점 하나의 2차 미분 또는 유한 샘플만으로 그런 보장을 주장하지 않는다.
ReLU 경계에서는 고전적 C² 공식을 그대로 적용하지 않고 직접 측정한 `R`를 사용한다.
오차가 개입 크기에 대해 단조라는 가정도 두지 않는다.

### 3.3 상호작용과 순서 효과

두 방향에 대해 `Q(s,t)=phi(F(z+s a+t b))`를 고정하고 다음을 측정한다.

`C(alpha,beta) = Q(alpha,beta)-Q(alpha,0)-Q(0,beta)+Q(0,0)`

아핀 `Q`에서는 항상 0이다. C² 직사각형 영역에서는 정확히
`C = integral_0^alpha integral_0^beta Q_st(s,t) dt ds`다.
국소 혼합 Hessian `Q_st(0,0)`는 작은 개입에서의 선도항이며
유한 개입의 `C`를 완전히 대체하지 않는다.
`Q`에는 관측 `phi`가 포함되므로 관측에서 생긴 비선형성도 구분한다.

상수 방향의 순차 잠재 이동은 비선형 생성기에서도 정확히 가환한다.
상태에 따라 달라지는 방향장, 재인코딩 또는 투영을 넣었을 때는 별도의
개입 연산 `T_a,T_b`를 정의하고 `F(T_b(T_a(z)))-F(T_a(T_b(z)))`를 평가한다.
혼합 Hessian과 Lie bracket은 서로 대체하지 않는다.

### 3.4 좌표와 인코더

좌표 변환 `h`가 가역이면 `F_new=F o h^-1`, `gamma_new=h o gamma`를 함께
적용한다. 그러면 관측한 경로 `q(t)`와 그 유한 반응은 동일하다.
이는 고전적 함수 합성의 성질이지 새로운 정리의 주장으로 삼지 않는다.

방향 `b`를 `c b`로 바꾸면 같은 물리적 개입에는 `t/c`를 써야 한다.
`||H(b,b)||/||Jb||`는 `|c|`에 비례하지만 동일한 개입의 `Delta`와 `R`는 같다.
곡선의 속도 변화, 곡선 자체의 굽힘, 생성 다양체의 법선 성분을 구분한다.
다양체 및 제2기본형 주장은 야코비안의 랭크가 국소적으로 일정한지와
해당 접공간을 먼저 확인해야 한다.

인코더 `E`는 `x=G(z)`, `zhat=E(x)`에 대해 출력 접선의 보존을 조사할 수 있다.

`DG_zhat DE_x DG_z b ≈ DG_z b`

이는 전체 잠재 좌표의 복원을 요구하지 않는다. 다른 좌표에서 동일한 방향을
비교하려면 개입도 운반해야 한다. 고정한 편집 방향 `b`를 그대로 재사용하는
문제는 별도 평가이며, 절댓값 saliency 상관만으로 미분 보존을 판정하지 않는다.

## 4. 설계 검증과 진행 조건

| 단계 | 검증 대상 | 통과 후 진행 | 실패 시 조치 |
|---|---|---|---|
| A | 정의·가정·반례의 정합성 | CPU 최소 검증 스크립트 실행 | 주장과 측정 정의 수정 |
| B | 해를 아는 선형·쌍선형·비매끄러운 함수, 좌표 변환, 영공간 | 실제 모델 소규모 파일럿 설계 확정 | 수학·구현 오류 수정 |
| C | 새로운 기준점에서 개입 반응 예측과 상호작용 검출의 효용 | 독립 평가 확장 | 효용 없는 구성 제거, 해당 주장 보류 |
| D | 기존 해석 평가 대비 차별성과 다른 모델에서의 재현 | 방법론 논문 구성 | 범용성·신규성 주장을 좁힘 |

단계 A/B 통과는 실제 모델의 성능, 의미 해석 또는 논문 신규성의 검증이 아니다.
본 단계의 구현 범위는 수학 검증 스크립트와 결과 기록까지다.

### CPU 반례 검증

`verify_design.py`는 외부 패키지·가중치·GPU 없이 다음을 검사한다.

1. 선형 함수에서도 절댓값 합성은 어긋나지만 유한 혼합 반응은 0이다.
2. 쌍선형 함수의 유한 혼합 반응은 해석해와 일치한다.
3. 혼합 반응이 있어도 상수 방향 이동의 순서 차이는 0이다.
4. 방향 단위 변경은 원래 미분 비율을 바꾸지만 동일한 개입 반응을 바꾸지 않는다.
5. 비선형 좌표 변환에서도 운반한 경로는 같고 새 직선 경로는 다르다.
6. 기준점의 2차 미분이 0이어도 유한 거리에서 1차 설명은 실패할 수 있다.
7. 유한 격자에서 오차가 0이어도 격자 사이의 오차는 클 수 있다.
8. 생성기의 영공간에서는 전체 잠재 역함수 조건이 불가능해도 출력 반응은 보존된다.
9. 정확한 복원과 같은 절댓값 반응만으로 고정 방향의 부호 보존을 알 수 없다.
10. 관측 변환 자체가 비선형 반응을 만들 수 있다.
11. 직선 위의 속도 변화도 2차/1차 비율을 키울 수 있다.

### 실제 모델 파일럿 설계

초기 대상은 기존 모델 하나와 사전에 고른 개입 네 종류다. 예시 규모는
교정 기준점 8개, 평가 기준점 16개이며 이는 작동 여부 확인용이지 논문 규모가 아니다.
방향 단위, 개입 크기 격자, 관측 표현, 수치 허용 오차, 비용 한도를 실행 전에 고정한다.
교정·검사에 쓴 개입 위치와 평가 위치를 분리한다. 같은 기준점의 반복 개입을
독립 표본으로 세지 않으며 후속 추론의 신뢰구간은 기준점 단위로 계산한다.

비교 대상: 0 반응 예측, 1차 JVP, 국소 2차 Taylor, 같은 모델 호출 예산의
유한차분/구간 선형 예측. 곡률 비율은 기존 진단 기준으로만 추가한다.
직접 관측한 `Delta`, `C`, `R`는 평가 목표이며 이를 이미 본 방법이 예측했다고
보고하지 않는다. 검사 후 보류하는 방식은 예측 방식과 다른 정보 예산으로 구분한다.

주평가: 미관측 개입의 부호·크기 오차와 상호작용 오차.
범위를 보류하는 경우에는 적용 비율과 적용 사례의 오차를 함께 보고한다.
모델/방향을 바꾼 대조에서 실제 반응이 변하면 설명도 그 변화를 반영해야 한다.
큰 변화 하나를 제거한 분석, 관측 표현 변경, 방향 부호 반전 결과를 따로 보고한다.
이미지 품질 향상, 미학적 선호 또는 편집 성공률을 본 연구의 주평가로 두지 않는다.

단계 C의 결과를 보기 전에는 성능 우월성이나 보편적 의미 축 발견을 주장하지 않는다.
실행 가능한 자산·수치 오차·비용을 확인한 뒤 C의 효과 크기와 진행 기준을 잠근다.

## 5. 선행 연구와 신규성 검토

- [Adebayo et al., Sanity Checks for Saliency Maps, NeurIPS 2018](https://papers.nips.cc/paper_files/paper/2018/hash/294a8ed24b1ad22ec2e7efea049b8737-Abstract.html): 설명이 모델·데이터에 의존하는지 검사하는 방법론이 이미 있다.
- [Kindermans et al., The (Un)reliability of saliency methods](https://arxiv.org/abs/1711.00867): 무관한 입력 변환으로 설명이 달라지는 문제와 입력 불변성을 다룬다.
- [Yeh et al., On the (In)fidelity and Sensitivity of Explanations, NeurIPS 2019](https://papers.nips.cc/paper_files/paper/2019/hash/a7471fdc77b3435276507cc8f2dc2569-Abstract.html): 충실도와 민감도를 구분하며 안정성만 최적화하면 무의미한 상수 설명도 최적일 수 있다.

따라서 안정성 검사, Taylor 잔차, 혼합 유한차분 또는 좌표 운반 자체는
신규 기여로 세지 않는다. 후보 기여는 **생성모델의 개입 해석에서 서로 다른
오류 원인을 구분하고, 미관측 개입에서 설명의 적용 범위를 더 정확히 판별하는
절차의 실증적·계산적 가치**다. 이는 현재 가설이며 기존 방법 대비 검증이 필요하다.
