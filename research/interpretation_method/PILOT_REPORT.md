# 첫 실제 모델 파일럿 결과

2026-09-07. 판정: **측정 구현과 재현성 검증 통과. 새 이론의 효용은 추가 검증 필요.**

## 1. 완료한 작업

부호를 보존한 개별 반응 `A`, `B`와 유한 혼합 반응
`C=Y_ab-Y_a-Y_b+Y_0`를 계산하는 측정 모듈을 구현했다.
선형 중첩·상쇄, 가산적 비선형, 쌍선형 결합, 비매끄러운 경계, 비선형 관측을
포함한 실제 구현 검사 11개가 통과했다.

기존 bedroom-256 생성기로 다음 프로토콜을 실행했다.

- 기준점 24개: 개발 8개, 고정 조건 반복 확인 16개.
- 기존 방향 8개 전체의 28쌍, 개입 크기 0.25/0.5/1.0, 부호 조합 4개.
- 생성 호출 9,240회, 방향 쌍 측정 8,064개, 누락·중복 없음.
- 본 측정 소요 시간 약 183.5초. 모델 로딩·사전 검증·별도 결과 검증 시간은 제외.
- 각 층에 원래 단위 방향을 적용하는 HiGAN 관례를 유지했다.
  전체 W+ 벡터 노름과 적용 층은 [directions.json](runs/bedroom_v1_pilot/directions.json)에 있다.

모델 출력은 클램핑하지 않은 원래 fp32 값이다. 차분과 축약 연산만 fp64로
수행했다. fp64 측정이 생성기 계산 자체의 fp64 정확도를 뜻하지 않는다.
세 개입 크기는 같은 방향 단위의 배수이며 의미 변화량을 동일하게 맞춘 것이 아니다.

## 2. 관찰

상대 혼합 반응은 `RMS(C)/(RMS(A)+RMS(B))`다.
다음 수치는 각 크기의 2,688개 측정 행에 대한 중앙값이며,
픽셀 비율·품질 저하율·실패 확률을 의미하지 않는다.

| 개입 크기 | 상대 혼합 반응 중앙값 | 사전 지정 10% 허용 기준에서 가산 설명 통과 |
|---|---:|---:|
| 0.25 | 17.66% | 0.335% |
| 0.5 | 24.85% | 0% |
| 1.0 | 32.50% | 0% |

현재 범위에서는 개입이 커질수록 단독 반응의 합으로 설명되지 않는 공동 반응이
커지는 경향을 관찰했다. 모든 사례에서 단조 증가한다는 주장은 아니다.

view 포함 조합의 상대 혼합 반응 중앙값은 23.27%, view 제외 조합은 26.14%였다.
이번 측정 조건에서 혼합 반응은 view에만 국한되지 않는다.
이를 방향별 고유 위험도 순위나 같은 의미 변화량에서의 비교로 해석하지 않는다.

개발 기준점의 중앙값은 25.97%, 반복 확인 기준점은 25.16%였다.
후자는 고정 조건의 특성 분석 반복이며 미관측 결과 예측의 검증이 아니다.

허용 오차에 따른 결과도 사전에 정한 범위로 함께 확인했다.
0.25 크기에서 가산 설명의 통과 비율은 상대 허용 오차 5%에서 0%,
10%에서 0.335%, 20%에서 68.30%였다. 따라서 한 임계값만을 선택해
보편적인 성공/실패를 주장할 수 없다.

## 3. 검증 근거

- [GPU 사전 검증](runs/bedroom_v1_preflight_retry1/preflight.json): 동일 입력의 반복 출력 차이 0,
  래퍼와 원래 synthesis 출력 차이 0. 당시 forward 평균 약 18.7ms.
- 사전 검증의 JVP/유한차분 비교는 별도 진단으로 기록했다. epsilon과 방향에 따라
  차이가 있으며, 직접 유한 반응을 측정하는 본 파일럿의 통과 근거로 쓰지 않았다.
- [전체 결과 감사](runs/bedroom_v1_pilot/verification.json): 8,064개 셀 전수 확인,
  소스 96개와 가중치/방향 입력 9개 해시 확인. 두 분해 항등식의 최대 폐합 오차
  약 `6.94e-17`.
- [독립 재계산](runs/bedroom_v1_pilot/verification_rerender.json): 기준점 92016의 사전 지정
  사례를 기존 `manipulate_wp`와 원래 synthesis로 4회 재생성했다.
  기준 출력·개별 반응·혼합 반응이 저장 텐서와 모두 최대 절대 차이 0으로 일치했다.
- 최초 사전 검증은 strict CUDA의 인덱스 대입 호환성 오류로 중단됐다.
  방향 배치를 CPU에서 구성하는 방식으로 수정했고, 실패 기록도 보존했다.

검증 명령:

```bash
python3 -m unittest discover -s research/interpretation_method -p test_measure.py -v
python3 research/interpretation_method/verify_pilot.py research/interpretation_method/runs/bedroom_v1_pilot
python3 research/interpretation_method/verify_pilot.py research/interpretation_method/runs/bedroom_v1_pilot --rerender-seed 92016
```

[프로토콜](protocol_bedroom_v1.json), [실행 manifest](runs/bedroom_v1_pilot/manifest.json),
[전체 행](runs/bedroom_v1_pilot/rows.jsonl), [요약](runs/bedroom_v1_pilot/summary.json)에
원본 결과와 재현 정보를 남겼다. 작업 트리가 dirty였다는 사실도 manifest에 기록했다.

## 4. 이 결과로 확인하지 못한 것

- 기존 중첩 지표보다 설명·예측·의미 해석이 더 정확하다는 비교.
- 사람이 부여한 의미 요인이나 통계적 독립성의 식별.
- 실제 의미 관측기에서 생성기와 관측기 영향의 일반적 분리.
  현재 제곱 관측 실험은 해석해가 있는 대조 조건이다.
- 다른 도메인/모델 계열로의 일반화와 논문 신규성.

분해 항등식의 정확성과 학습 모델에 혼합 반응이 있다는 사실만으로는
새 방법의 유용성이 입증되지 않는다. 기존 절댓값 상관과 이번 반응 크기는
같은 지표가 아니므로 수치를 직접 대조해 성능 향상이라고 말하지 않는다.

## 5. 다음 단계의 판단

**측정 기반은 사용할 수 있다. 가산 설명의 적용 범위를 예측하는 단계는
개입 범위를 다시 설계한 뒤 진행해야 한다.**

10% 허용 오차에서 현재 범위의 8,064개 중 통과 사례는 9개뿐이다.
이 자료로 이진 예측기를 만들면 거의 항상 비가산이라고 답하는 기준만으로도
높은 정확도를 얻으므로, 그 정확도는 연구 진전을 뜻하지 않는다.

다음 실험은 개발 전용 기준점에서 0.25보다 작은 개입을 조사해,
수치 잡음보다 충분히 크면서 가산/비가산 조건을 함께 포함하는 범위를 확인한다.
현재 임계값을 결과에 맞춰 바꾸지 않는다. 후속 프로토콜과 새로운 평가 기준점을
고정한 뒤 단순 가산, 중첩, 국소 미분, 같은 예산의 유한 관측 방법을 비교한다.

이렇게 해야 '현상을 계산했다'에서 '어떤 설명을 믿어야 할지 더 잘 판단한다'로
연구가 진전되는지 검증할 수 있다.
